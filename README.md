# mOps

> A desktop YouTube Music client for Windows, built with Flutter.
> Material 3 Expressive UI, its own window title bar, and word-by-word
> (karaoke) lyrics. Unofficial — not affiliated with Google or YouTube.

Неофициальный клиент **YouTube Music**. Десктоп в первую очередь — **Windows**,
но код собирается и под Linux, и под macOS. Интерфейс — Material 3 Expressive.

Чем это отличается от вкладки с музыкой в браузере:

- это отдельное приложение со **своей заголовочной панелью окна** — безрамочное,
  с логотипом, динамическим заголовком и круглыми кнопками в духе Material, а не
  системными прямоугольниками Windows;
- тексты песен умеют **пословную разметку** (караоке с подсветкой слов), а не
  только построчную;
- настройки, кэш текстов и сессия лежат локально, в каталоге данных приложения.

## Возможности

### Каталог и поиск

- **Главная** с бесконечной прокруткой секций, **Обзор** (новые релизы, чарты,
  настроения и жанры, подкасты) и **Поиск**.
- Поиск по трекам, альбомам, исполнителям, плейлистам и видео; можно ограничить
  выдачу только своей библиотекой.
- Страницы **альбома**, **исполнителя** и **плейлиста**.
- **Очередь** с перетаскиванием, «играть следующим» и «в очередь»; при
  завершении очереди подключается авторадио по треку.
- Перемешивание, повтор (очередь / трек), автовоспроизведение.

### Плеер

- Движок воспроизведения — **libmpv** (через `media_kit`).
- Качество звука: экономия трафика / среднее / максимум.
- **Источник потока**: visionOS (по умолчанию), Android VR, iOS, клиент
  библиотеки — на случай, если YouTube начнёт требовать для одного из клиентов
  вход или PO-токен.
- Перемотка, громкость, скорость воспроизведения, выбор стиля полосы перемотки
  и ползунка громкости.
- Полноэкранный плеер с фоном из обложки (градиент или размытие) и плавающий
  островок плеера.

### Библиотека и аккаунт

- **Коллекция** с фильтрами: библиотека, «Мне нравится», плейлисты, треки,
  исполнители, альбомы, подписки.
- Вход в аккаунт: **OAuth Device Flow**, вход по **cookie** (`SAPISID`) или
  **встроенный браузер** (WebView2 на Windows, WKWebView на macOS, WebKitGTK на
  Linux). Токен обновляется автоматически.
- **Перенос плейлистов из Spotify**: вход в Spotify и импорт списков в YouTube
  Music.

### Интерфейс

- Material 3 Expressive; тема из обложки играющего трека или из акцентного
  цвета; тональная / нейтральная / монохромная палитра, чистый чёрный фон.
- **Своя заголовочная панель окна** (только Windows): логотип, динамический
  заголовок (название трека, иначе — раздела), круглые кнопки, перетаскивание за
  любое место шапки, двойной клик — развернуть. Окно безрамочное, границы для
  изменения размера рисуются сами.
- Плавающие островки навигации и плеера, две раскладки (узкая и широкая),
  правая панель с режимами «Плеер» и «Очередь», сворачиваемая боковая панель.
- **Горячие клавиши** и палитра команд по `Ctrl+K`.
- Масштаб интерфейса: автоматически по масштабу рабочего стола или вручную.
- Типографика: Poppins, для кириллицы подставляется Montserrat.

### Интеграции

- **Discord Rich Presence**: текущий трек, обложка и кнопка «Слушать в YouTube
  Music». Свой клиент локального IPC Discord — без нативных зависимостей. Нужен
  Application ID из Discord Developer Portal.

## Тексты песен

### Источники

Подключены (`LyricsSource`):

| Источник | Что даёт |
|---|---|
| Текст YouTube Music | вкладка «Текст», без времён |
| Субтитры видео | дорожка видео, время у строк |
| BetterLyrics | Apple Music (TTML), пословная синхронизация |
| YouLy+ | зеркала Lyricify: TTML или LRC |
| LRCLIB | открытая база, текст с временами |
| KuGou | внешняя база (в том числе караоке QRC) |
| Unison | внешняя база, текст с временами |
| Paxsenix | Apple Music и Musixmatch — **нужен ключ** в настройках |
| Megalobiz, SimpMusic | в списке есть, но по умолчанию отключены |

Поддерживаются форматы **TTML** (Apple Music), **LRC**, **QRC** (караоке QQ
Music) и обычный текст без времён.

### Как выбирается текст

Все источники опрашиваются **параллельно**: на каждый даётся бюджет 5 секунд,
весь поиск завершается не позже 6 секунд, поэтому медленная база не держит
пользователя в ожидании.

Каждый ответ оценивается, и **главный критерий — тип синхронизации**. Порядок
типов:

1. **караоке** — время размечено у нескольких слов внутри строки;
2. **пословная** — время у слов, по одному слову на строку;
3. **построчная** — время только у строк;
4. **без времён** — подсветить и прокрутить нечего.

В режиме «Авто» побеждает текст с более подробной разметкой; внутри одного типа
источники сравниваются **по порядку из настроек** (первый — приоритетный).
Порядок по умолчанию: YouLy+, BetterLyrics, Paxsenix, KuGou, LRCLIB, Unison.
Тексты YouTube Music и субтитры идут в самом конце — у них нет метаданных для
оценки. Вручную выбранный источник авторитетен: если в нём пусто, подмены
чужим текстом не будет.

Караоке считается таковым только когда размечено **большинство** строк — иначе
база со словами лишь в припеве выдавала бы себя за караоке.

### Кэш на диске

Найденные тексты сохраняются в `lyrics_cache.json` рядом с данными приложения.
Ключ — «id трека + источник». Запись живёт **7 суток** (TTL), всего хранится не
больше 500 записей, при переполнении вытесняются самые старые. Пустой ответ не
пишется, чтобы разовый сбой базы не затёр уже найденный текст.

### Оффсет на трек

Синхронизацию текста можно сдвинуть для конкретного трека: шаг 0,5 с, предел
±30 с. Значение хранится по id трека и применяется и к подсветке строки, и к
караоке.

### Показ

Автопрокрутка, подсветка активной строки и слов, размытие неактивных строк,
настройка размера текста и межстрочного интервала, поиск по тексту и
**романизация** (латиница под оригиналом) для японского, корейского, китайского,
хинди, русского, тайского, арабского и греческого.

## Обход блокировок

Провайдер может обрывать соединение с YouTube по имени домена в TLS-рукопожатии
(SNI) или фильтровать DNS. В приложении два независимых механизма, оба
устанавливаются глобально через `HttpOverrides` и действуют на весь трафик
(`package:http`, загрузку обложек, `youtube_explode_dart`):

- **Подмена хоста (domain fronting).** Соединение идёт на разрешённый узел
  Google, а настоящее имя передаётся в заголовке `Host`. Обходит и блокировку по
  SNI, и фильтрацию DNS. Медиахосты (`googlevideo.com`) намеренно не
  подменяются: у них собственный backend, и через фронт-узел запрос до него не
  доходит — для звука нужен прокси или системный обход.
- **Прокси SOCKS5 / HTTP.** Можно указать вручную, либо приложение само найдёт
  запущенный локальный клиент (v2rayA, v2rayN, Clash, Sing-box, Tor и другие) —
  проверка идёт **настоящим подключением** к медиахосту, а не фактом «порт
  открыт».
- **Дробление первого пакета TLS** — дополнительная опция для сетей, где SNI
  ищут в одном сегменте.

При запуске приложение **само проверяет доступность**: если прямой доступ есть,
свой обход выключается (под VPN он только мешает); если медиахост заблокирован —
ищет локальный прокси. Настройки — **Настройки → Доступ к сети → Обход
блокировок**, там же кнопка «Проверить соединение».

## Сборка

Нужен Flutter (в проекте зафиксирован **3.47.7 stable**) и Dart 3.13+.

```bash
flutter pub get
```

### Windows

```bash
flutter build windows --release --no-tree-shake-icons
```

Флаг **`--no-tree-shake-icons` обязателен**: часть иконок лежит в enum и
кортежах, и штатное «вырезание» неиспользуемых иконок удаляет их из шрифта — в
запущенном приложении они рисовались бы пустыми квадратами.

Две вещи, о которые легко споткнуться:

- **libmpv.** Сборка `media_kit_libs_windows_audio` ищет архив `mpv-dev-*.7z` в
  каталоге `build/windows/x64`. Обычно он скачивается автоматически с GitHub; на
  сети без доступа к релизам положите архив туда вручную (имя зафиксировано в
  пакете — `mpv-dev-x86_64-20230924-git-652a1dd.7z`).
- **Шаг `INSTALL`.** Windows-сборка Flutter копирует файлы в
  `CMAKE_INSTALL_PREFIX`. Если в кэше CMake он указывает в `Program Files`, файлы
  уйдут туда, а не в `build/windows/x64/runner/Release`. В этом случае удалите
  каталог `build/windows` и пересоберите — префикс будет выставлен заново; либо
  поправьте его в `build/windows/x64/CMakeCache.txt`.

Готовый установщик Windows собирается Inno Setup из `packaging/windows/mops.iss`.

### Linux

```bash
flutter build linux --release --no-tree-shake-icons
```

Нужны GTK3 и системный `libmpv` (пакет `mpv` / `libmpv`), а для встроенного входа
в аккаунт — WebKitGTK 4.1. Для ярлыка в меню приложений есть
`packaging/install-desktop.sh`, для запуска при разработке — `run.sh`.

### macOS

```bash
brew install mpv
flutter build macos --release --no-tree-shake-icons
```

### Конвейер

`.github/workflows/build.yml` собирает все три платформы на GitHub Actions и
публикует архивы (и установщик Windows) в Releases по тегу вида `v*`.

## Данные приложения

Каталог данных берётся у системы (`getApplicationSupportDirectory`). На Windows
это:

```
%APPDATA%\com.mops\mops\
```

Здесь лежат настройки (`shared_preferences`) и кэш текстов `lyrics_cache.json`.

## Служебные скрипты

В `tool/` — консольные проверки, запускаются обычным `dart run`:

| Скрипт | Зачем |
|---|---|
| `diagnose.dart` | пошаговая проверка сети: DNS, API напрямую и с подменой, медиасервер |
| `player_probe.dart` | перебор клиентов YouTube и получение ссылки на поток |
| `audio_range_check.dart` | загрузка потока кусками, как это делает плеер |
| `lyrics_sources_check.dart`, `lyrics_check.dart` | проверка баз текстов |
| `dpi_probe.dart`, `front_probe.dart` | TLS-рукопожатие, подмена хоста, фрагментация |
| `proxy_check.dart`, `proxy_retry_check.dart` | проверка прокси и повторов |
| `feature.sh` | отдельное рабочее дерево и ветка на каждую фичу, тег-предрелизы |

## Известные ограничения

- **Часть баз текстов недоступна из отдельных сетей.** Каждый источник ограничен
  бюджетом в 5 секунд; недоступный просто не отвечает, и поиск идёт дальше.
- **Megalobiz и SimpMusic** исключены из порядка источников по умолчанию — их
  хосты недоступны. В коде источники остались, выбрать их вручную можно.
- **Paxsenix (Musixmatch)** требует ключ: без него источник пропускается.
- **Свайп по строке трека** (`trackSwipeAction`) хранится в настройках, но в
  строке списка не применяется.
- **Уровень звука** движок в Dart не отдаёт, поэтому «живость» волны в плеере
  условная — считается от позиции, темпа и громкости.
- **Подмена хоста не обходит блокировку медиахостов** (`googlevideo.com`) — для
  звука нужен прокси или системный обход.
- **Своя шапка окна и безрамочный режим** — только Windows.
- Клиент внутреннего API YouTube Music может перестать работать — тогда помогает
  смена источника потока в настройках.
